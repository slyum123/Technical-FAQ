# Technical-FAQ

> AI / Computer / Communication 技术问题汇总知识库

本仓库用于每日沉淀技术问答，涵盖 AI、计算机、通信等领域。

## 目录结构

```
Technical-FAQ/
├── README.md               # 项目说明
├── docs/                   # 每日 FAQ 文档
│   └── 2026-08/            # 按月份归档
│       └── 2026-08-13-FAQ.md
├── templates/              # 模板文件
│   └── daily-faq-template.md
```

## 文档命名规范

- 每日 FAQ 文档：`YYYY-MM-DD-FAQ.md`
- 存放路径：`docs/YYYY-MM/YYYY-MM-DD-FAQ.md`

## 内容格式

每篇每日 FAQ 包含：
- 日期
- 问题列表（含分类标签：AI / Computer / Communication / Other）
- 每个问题的简要回答和关键要点
- 信息来源标注

## 更新机制

- 每日自动汇总当天技术问题
- 按月归档到对应目录
- 定期回顾整理高频问题，形成专题 FAQ
