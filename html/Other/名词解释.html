术语目录： 低秩投影压缩
低秩投影压缩
Low-Rank Projection Compression / Latent Compression

定义

利用数据（矩阵/向量序列）的低秩特性，通过线性投影将高维表示映射到低维潜空间（latent space）进行压缩存储与计算，需要时再从潜向量衍生出高维表示的技术。其核心是：用"低维潜向量 + 低秩映射"近似表达原本高维的数据，以信息冗余换取存储与计算效率。

数学原理

给定矩阵 A（m×n），奇异值分解（SVD）：

A = UΣVT，其中 Σ = diag(σ₁ ≥ σ₂ ≥ … ≥ σmin(m,n))

保留前 k 个最大奇异值（k ≪ min(m,n)），得到秩 k 近似：

A ≈ Ak = Uk Σk VkT

根据 Eckart–Young 定理，Ak 是 A 在秩 k 约束下的最优近似（最小化 Frobenius 范数误差）。压缩率与精度取决于奇异值的衰减速度：奇异值衰减越快，低秩近似越精确，需要的 k 越小。

数值示例：4 维表示如何降到 2 维

下面用一个具体向量演示"投影—降维—重建"的完整过程，说明维度确实可以降低，且误差可控。

步骤 1：原始高维表示

假设某个 token 的隐状态是一个 4 维向量：

h = [6.0, 8.0, 6.4, 7.6]T ∈ ℝ4

观察发现：h 的后两个分量近似是前两个分量的"复制"（h3 ≈ h1，h4 ≈ h2），也就是说这 4 个数实际只由约 2 个独立变量决定——这正是低秩/低维子结构的体现。

步骤 2：定义低秩投影矩阵

学习上投影矩阵 U ∈ ℝ4×2 和下投影矩阵 W ∈ ℝ2×4：

U = [[1, 0], [0, 1], [1, 0], [0, 1]]，  W = [[0.5, 0, 0.5, 0], [0, 0.5, 0, 0.5]]

U 把 2 维潜向量扩展回 4 维；W 把 4 维向量压缩到 2 维潜空间。

步骤 3：计算潜向量（压缩）

c = W · h：

c1 = 0.5×6.0 + 0×8.0 + 0.5×6.4 + 0×7.6 = 6.2
c2 = 0×6.0 + 0.5×8.0 + 0×6.4 + 0.5×7.6 = 7.8
⇒ c = [6.2, 7.8]T ∈ ℝ2

原始需要存储 4 个浮点数，现在只需存储 2 个，单 token 存储量减半。

步骤 4：重建高维表示

h' = U · c：

h' = [1×6.2 + 0×7.8, 0×6.2 + 1×7.8, 1×6.2 + 0×7.8, 0×6.2 + 1×7.8]T = [6.2, 7.8, 6.2, 7.8]T

步骤 5：比较误差

重建误差 = h − h' = [−0.2, 0.2, 0.2, −0.2]T
||h − h'||F = √((−0.2)2 + 0.22 + 0.22 + (−0.2)2) = 0.4
||h||F = √(6.02 + 8.02 + 6.42 + 7.62) ≈ 14.1
相对误差 ≈ 0.4 / 14.1 ≈ 2.8%

维度从 4 降到 2（压缩 2 倍），相对误差仅约 2.8%。

步骤 6：推广到序列（KV cache 场景）

若序列长度 L = 4096，每个 token 存储 4 维：

  • 原始存储量：4 × 4096 = 16,384 个浮点数
  • 压缩后存储量：2 × 4096 = 8,192 个浮点数
  • 若每个浮点 2 字节（BF16），原始约 32 KB，压缩后约 16 KB

维度减半直接带来存储减半；当潜空间维度 dc 远小于原始维度 d 时（如 MLA 中 d=7168，dc=512），压缩倍数可达 10 倍以上。

大模型中的典型应用

  • MLA（Multi-head Latent Attention，DeepSeek-V2/V3）： 对多头注意力的 Key 与 Value 做联合低秩压缩。将当前 token 的隐状态 ht 投影为低维潜向量 ct = WDKV ht， 仅缓存 ct，K/V 由潜向量经上投影矩阵衍生。KV cache 从 O(2·d_h·n_h·l) 降至 O(d_c·l)， DeepSeek-V3 中 KV cache 从 655GB 降至 9.2GB（约 71 倍压缩）。 推理时用矩阵吸收（absorb）技巧合并上投影，避免显式解压大矩阵。
  • LoRA（Low-Rank Adaptation）微调： 冻结预训练权重 W，将权重增量分解为低秩乘积 ΔW = B·A（A: r×d，B: d×r，r ≪ d）。 只训练 A、B，可训练参数量减少数个数量级，适配成本极低。
  • 权重/嵌入压缩：模型剪枝与蒸馏中对权重矩阵做 SVD 截断，或对词嵌入做低秩分解。

为什么有效

  • 真实数据的表示（词嵌入、注意力模式、激活值）通常集中在低维子空间中，高维空间存在大量冗余与强相关性
  • 低秩投影相当于学习数据的主成分方向，保留主要信息、丢弃次要冗余

优点与缺点

  • 优点：显著减少存储（KV cache、权重）、降低计算量（低维矩阵乘法）、减少内存带宽占用（推理的主要瓶颈）
  • 缺点：存在信息损失（由截断奇异值决定，通常可控）；压缩/解压引入额外算子（可通过吸收技巧、算子融合缓解）；当数据本身不满足低秩假设时效果下降

关键结论

  • 低秩投影压缩的本质：用"低维潜空间表示 + 低秩映射"利用信息冗余换取存储与计算效率
  • MLA 的 KV 压缩是低秩投影压缩在注意力机制中最成功的工程应用之一
  • 压缩维度 k（或潜向量维度 dc）是关键超参数：过小丢失信息，过大压缩率不足
  • 无损化技巧（矩阵吸收、融合 Kernel）是低秩压缩落地的关键配套手段
