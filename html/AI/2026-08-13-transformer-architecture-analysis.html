Section 1

Positional Encoding 位置编码

import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class PositionalEncoding(nn.Module):
    """位置编码：为输入嵌入注入位置信息"""

    def __init__(self, d_model, max_len=5000):
        super().__init__()
        # 创建位置编码矩阵 [max_len, d_model]
        pe = torch.zeros(max_len, d_model)
        # position: [max_len, 1] 表示每个位置的索引
        position = torch.arange(0, max_len).unsqueeze(1).float()
        # div_term: [d_model/2] 频率衰减项
        div_term = torch.exp(
            torch.arange(0, d_model, 2).float()
            * (-math.log(10000.0) / d_model)
        )
        # 偶数维度用 sin，奇数维度用 cos
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        # 增加 batch 维度 [1, max_len, d_model]
        pe = pe.unsqueeze(0)
        # 注册为 buffer（不参与梯度更新，但会随模型保存/加载）
        self.register_buffer('pe', pe)

    def forward(self, x):
        """
        x: [batch_size, seq_len, d_model]  词向量序列
        return: [batch_size, seq_len, d_model]  注入位置信息后的序列
        """
        # 直接将位置编码加到输入嵌入上
        return x + self.pe[:, :x.size(1)]

语义描述

Transformer 完全基于注意力机制，没有 RNN/CNN 的天然时序结构，因此无法感知 token 的先后顺序。Positional Encoding 的作用就是给每个位置的词向量注入绝对位置信息，使模型能区分 "猫追狗" 和 "狗追猫"。

使用 sin/cos 交替函数的精妙之处在于：

  • 周期性：sin/cos 是周期函数，不同维度使用不同频率，使模型能捕捉相对位置关系
  • 有界性：值域 [-1, 1]，不会破坏词向量的量纲
  • 可外推：对超出训练长度的位置，sin/cos 仍能产生合理的编码值

频率衰减项 div_term 使低维度变化快（捕捉精细位置）、高维度变化慢（捕捉粗粒度位置），类似于时钟的秒针和时针。

关键要点：
  • 位置编码是加法操作，不是拼接，因此不改变维度
  • register_buffer 使 pe 不参与梯度更新但能随 model.to(device) 自动迁移
  • 输入输出形状不变：[batch, seq_len, d_model]

工作原理深度拆解

这段代码的数学原型是论文中的正弦/余弦位置编码：

PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

代码用了一个技巧把上面公式转成向量运算：

  1. position 形状 [max_len, 1]，表示每个位置的序号 0,1,2,...
  2. div_term = exp(torch.arange(0, d_model, 2) * (-log(10000)/d_model)) 等价于 1 / 10000^(2i/d_model)
  3. position * div_term 把每个位置 pos 乘到每个频率上，得到 [max_len, d_model/2]
  4. 偶数维放 sin，奇数维放 cos，最终得到 [max_len, d_model]

数值示例（d_model=4）

假设 max_len=3，d_model=4，则：

position = [[0], [1], [2]]
div_term = [1/10000^0, 1/10000^(2/4)] = [1.0, 0.01]
pe[0, 0::2] = sin(0 * [1.0, 0.01]) = [0, 0]
pe[0, 1::2] = cos(0 * [1.0, 0.01]) = [1, 1]
pe[1, 0::2] = sin(1 * [1.0, 0.01]) = [0.84, 0.01]
pe[1, 1::2] = cos(1 * [1.0, 0.01]) = [0.54, 1.0]
# 最终 pe[0] = [0, 1, 0, 1]
#       pe[1] = [0.84, 0.54, 0.01, 1.0]

register_buffer 让 pe 不参与反向传播，但会随 model.to(device) 自动搬到 GPU；forward 里用切片 self.pe[:, :x.size(1)] 取前 seq_len 个位置，再与输入相加。

Scaled Dot-Product Attention 缩放点积注意力

def scaled_dot_product_attention(Q, K, V, mask=None):
    """
    核心注意力计算函数

    Q: [batch, n_heads, seq_len_q, d_k]  查询矩阵
    K: [batch, n_heads, seq_len_k, d_k]  键矩阵
    V: [batch, n_heads, seq_len_v, d_v]  值矩阵  (seq_len_k == seq_len_v)
    mask: [batch, 1, seq_len_q, seq_len_k] 或 None  掩码

    return: (output, attn_weights)
      output:      [batch, n_heads, seq_len_q, d_v]
      attn_weights: [batch, n_heads, seq_len_q, seq_len_k]
    """
    d_k = Q.size(-1)

    # Step 1: Q 和 K^T 做矩阵乘法，得到注意力分数
    # [batch, heads, seq_q, d_k] x [batch, heads, d_k, seq_k]
    # = [batch, heads, seq_q, seq_k]
    scores = torch.matmul(Q, K.transpose(-2, -1))

    # Step 2: 缩放 —— 除以 sqrt(d_k)
    scores = scores / math.sqrt(d_k)

    # Step 3: 掩码（可选）—— 将需要屏蔽的位置设为 -inf
    if mask is not None:
        scores = scores.masked_fill(mask == 0, -1e9)

    # Step 4: Softmax 归一化 —— 将分数转为概率分布
    attn_weights = F.softmax(scores, dim=-1)

    # Step 5: 用注意力权重对 V 加权求和
    # [batch, heads, seq_q, seq_k] x [batch, heads, seq_k, d_v]
    # = [batch, heads, seq_q, d_v]
    output = torch.matmul(attn_weights, V)

    return output, attn_weights

语义描述

这是 Transformer 的注意力核心公式，实现了 Attention(Q,K,V) = softmax(QK^T / sqrt(d_k)) * V。其语义是："给定一个查询 Q，在所有键 K 中找到最相关的，然后取出对应值 V 的加权组合"。

类比理解：你在图书馆找书（Q），每本书的书名是 K，书的内容是 V。QK^T 计算"查询与每个书名的相似度"，softmax 将相似度转为概率（权重），最后用权重对内容加权求和，得到最相关的信息组合。

五个步骤的语义

  • QK^T（点积）：计算 Query 与每个 Key 的相似度，越大越相关
  • / sqrt(d_k)（缩放）：防止 d_k 过大时点积值过大导致 softmax 梯度消失。当 d_k 较大时，QK^T 的方差正比于 d_k，除以 sqrt(d_k) 将方差拉回 1 附近
  • mask（掩码）：在 Decoder 中屏蔽未来位置（因果掩码），或在 padding 位置屏蔽注意力
  • softmax（归一化）：将任意实数分数转为 [0,1] 概率分布，且总和为 1
  • matmul(attn, V)（加权求和）：按注意力权重对所有 Value 做加权平均，高权重的 Value 贡献更大
关键要点：
  • 缩放因子 1/sqrt(d_k) 是论文的核心创新之一，解决了高维点积导致 softmax 饱和的问题
  • mask 使用 -1e9 而非 -inf，避免 NaN
  • 这个函数没有可学习参数，是纯数学运算

工作原理深度拆解

这 5 行代码本质上是在实现一个可微分的“软查询”。用具体形状走一遍就清楚了：

  1. QK^T：Q 形状 [B, H, Lq, dk]，K 转置后形状 [B, H, dk, Lk]。矩阵乘法把最后两维相乘，得到 [B, H, Lq, Lk]。每个元素 scores[b,h,i,j] = Q[b,h,i,:] · K[b,h,j,:]，即“第 i 个查询和第 j 个键有多像”。
  2. / sqrt(dk)：当 dk=64 时，随机向量的点积方差大约是 dk 倍。除以 sqrt(dk)=8 后，方差回到 1，softmax 输入不会太大。
  3. masked_fill：把 mask=0 的位置填成 -1e9。softmax 里 exp(-1e9)≈0，所以这些位置权重几乎为 0。
  4. softmax：在最后一个维度（key 维）做归一化，使每行和为 1，得到注意力概率分布。
  5. matmul(attn, V)：attn [B,H,Lq,Lk] 乘 V [B,H,Lk,dv]，得到 [B,H,Lq,dv]。每行是 V 的加权平均。

数值示例

dk=4, Q=[1,0,1,0], K=[1,0,1,0], V=[10,20,30,40]
Q·K^T = 2  (两个相同向量的点积)
score = 2 / sqrt(4) = 1.0
softmax 权重 ≈ [1.0] (只有一个 key 时)
output = 1.0 * V = [10,20,30,40]
# 实际有多个 key 时，V 会被多个值加权组合

Multi-Head Attention 多头注意力

class MultiHeadAttention(nn.Module):
    """多头注意力：将 Q/K/V 分到多个头并行计算注意力"""

    def __init__(self, d_model, n_heads, dropout=0.1):
        super().__init__()
        assert d_model % n_heads == 0, "d_model 必须能被 n_heads 整除"

        self.d_model = d_model      # 模型维度，如 512
        self.n_heads = n_heads      # 注意力头数，如 8
        self.d_k = d_model // n_heads  # 每个头的维度，如 64

        # 四个线性投影层：分别用于 Q, K, V 的投影和输出投影
        self.W_q = nn.Linear(d_model, d_model)  # Query 投影
        self.W_k = nn.Linear(d_model, d_model)  # Key 投影
        self.W_v = nn.Linear(d_model, d_model)  # Value 投影
        self.W_o = nn.Linear(d_model, d_model)  # 输出投影

        self.attn_weights = None  # 保存注意力权重（用于可视化）
        self.dropout = nn.Dropout(dropout)

    def forward(self, Q, K, V, mask=None):
        """
        Q, K, V: [batch_size, seq_len, d_model]
        mask: [batch_size, 1, 1, seq_len] 或 None

        return: [batch_size, seq_len, d_model]
        """
        batch_size = Q.size(0)

        # Step 1: 线性投影 —— 将 Q/K/V 分别乘以权重矩阵
        Q = self.W_q(Q)  # [batch, seq_len, d_model]
        K = self.W_k(K)
        V = self.W_v(V)

        # Step 2: 分头 —— 将 d_model 拆分为 n_heads x d_k
        # [batch, seq_len, d_model] -> [batch, seq_len, n_heads, d_k]
        # -> [batch, n_heads, seq_len, d_k]
        Q = Q.view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)
        K = K.view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)
        V = V.view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)

        # Step 3: 并行计算每个头的注意力
        attn_output, self.attn_weights = scaled_dot_product_attention(Q, K, V, mask)

        # Step 4: 合并多头 —— 将 n_heads 个头拼接回 d_model
        # [batch, n_heads, seq_len, d_k] -> [batch, seq_len, n_heads, d_k]
        # -> [batch, seq_len, d_model]
        attn_output = attn_output.transpose(1, 2).contiguous()
        attn_output = attn_output.view(batch_size, -1, self.d_model)

        # Step 5: 输出线性投影
        output = self.W_o(attn_output)

        return output

语义描述

Multi-Head Attention 是 Transformer 的核心创新。它不是做一次注意力，而是做 n_heads 次并行注意力，每个头学习关注不同的语义子空间。

类比理解：阅读一篇文章时，你可能同时关注"语法结构"、"情感色彩"、"实体关系"等多个维度。单头注意力只能学一个维度，多头注意力让模型同时从多个视角理解序列。

五个步骤的语义

  • 线性投影：用 W_q/W_k/W_v 将输入映射到不同的表示空间。这不是简单的维度变换，而是学习"应该关注什么"
  • 分头：将 d_model=512 维拆成 8 个 64 维的子空间。每个头独立处理 64 维，计算量不增加
  • 并行注意力：8 个头同时计算 Scaled Dot-Product Attention，互不干扰
  • 合并：将 8 个头的输出拼接回 512 维。contiguous() 确保内存连续以支持 view 操作
  • 输出投影：用 W_o 对拼接后的结果再做一次线性变换，融合多视角信息

三种使用模式

  • Self-Attention（自注意力）：Q=K=V=同一输入。用于 Encoder，每个位置关注所有位置
  • Masked Self-Attention：Q=K=V=同一输入 + 因果掩码。用于 Decoder，每个位置只能关注当前及之前的位置
  • Cross-Attention（交叉注意力）：Q 来自 Decoder，K=V 来自 Encoder。让 Decoder 在生成时参考 Encoder 的输出
关键要点：
  • 多头注意力的总计算量与单头注意力相同（因为 d_k = d_model / n_heads）
  • 4 个线性层的参数量：4 × d_model × d_model = 4 × 512² ≈ 1M 参数
  • transpose(1, 2) 将 head 维度提到前面，使不同头并行计算
  • 输入输出形状不变：[batch, seq_len, d_model]

深度拆解：投影（Projection）与“降维”

你问到的“投影”和“降维”，核心就在 self.W_q / W_k / W_v / W_o 这四层线性变换里。下面逐层拆开讲。

1. nn.Linear 在做什么？

PyTorch 的 nn.Linear(in_features, out_features) 实现的是：

y = x @ W.T + b

其中 W 形状 [out, in]，b 形状 [out]。可以把 W 的每一行理解成一条“关注方向”：输出向量的第 i 维 = W 的第 i 行与输入 x 做内积，也就是 x 在这条方向上的投影长度。

2. W_q/W_k/W_v 的输入输出都是 512→512，怎么叫“降维”？

注意：投影之后还要分头。以 d_model=512、n_heads=8 为例：

  1. self.W_q(x) 先把 x 映射到一个 512 维的“Query 专属空间”。这一步没有降维，只是重新组合了 512 维信息。
  2. view(batch, -1, 8, 64) 把 512 维切成 8 段，每段 64 维。
  3. transpose(1, 2) 把头维度提到前面，变成 [batch, 8, seq_len, 64]。

所以，从全局看维度没变（512），但从单个头的视角看，每个头只处理 64 维。这就是你感觉到的“降维”：一个 512 维的复杂问题，被拆成 8 个并行的 64 维子问题。

3. 为什么要先投影再分头，而不是直接切原始 x？

直接切原始 x 相当于机械地把 512 维分成 8 段，每段固定对应某些原始维度。这样不同头只能看到固定的信息子集，无法灵活学习。先投影再分头，意味着：

  • 每个头先用自己独立的 W_q/W_k/W_v 对 512 维信息做重新加权
  • 再从中取出它最需要的 64 维
  • 每个头可以专注于不同语义子空间（语法、指代、位置、情感等）

因此，投影的本质是让模型自己学习“每个头应该看什么”，而不是人为主规定。

4. W_o 是做什么的？

8 个头各自输出 64 维，拼接后是 512 维。W_o 对这 512 维再做一次线性组合，决定：

  • 哪些头的信息应该被加强
  • 哪些头的信息应该被抑制
  • 不同头的信息如何融合成最终的上下文向量

如果把多头注意力比作“8 个专家分别给出意见”，W_o 就是“综合各专家意见并给出最终结论”的整合层。

5. 形状变化完整链路

x:        [batch, seq_len, d_model] = [2, 3, 512]
W_q(x):   [2, 3, 512]        (仍是 d_model)
view+transpose: [2, 8, 3, 64]   (8 个头，每头 64 维)
attn_out: [2, 8, 3, 64]
transpose+view: [2, 3, 512]     (8×64=512 拼接回来)
W_o:      [2, 3, 512]        (最终输出)

Position-wise Feed-Forward Network 位置前馈网络

class PositionwiseFeedForward(nn.Module):
    """位置前馈网络：对每个位置独立做两层线性变换 + ReLU"""

    def __init__(self, d_model, d_ff, dropout=0.1):
        super().__init__()
        # 第一层：d_model -> d_ff （升维）
        self.w_1 = nn.Linear(d_model, d_ff)
        # 第二层：d_ff -> d_model （降维回原始维度）
        self.w_2 = nn.Linear(d_ff, d_model)
        self.dropout = nn.Dropout(dropout)

    def forward(self, x):
        """
        x: [batch_size, seq_len, d_model]
        return: [batch_size, seq_len, d_model]

        对每个 token 独立做：FFN(x) = W_2 * ReLU(W_1 * x + b_1) + b_2
        """
        # 升维 -> ReLU 激活 -> Dropout -> 降维
        return self.w_2(self.dropout(F.relu(self.w_1(x))))

语义描述

FFN 是一个逐位置的两层 MLP，对序列中每个 token 的向量独立做变换。"Position-wise" 的含义是：不同位置之间不交互，每个位置用相同的权重独立处理。

先升维（512→2048）再降维（2048→512）的设计动机：

  • 升维：在高维空间中增加非线性表达能力，让模型学到更复杂的特征变换
  • 降维：将信息压缩回 d_model 维，保持残差连接的维度一致
  • ReLU：引入非线性。注意力机制本身是线性的（矩阵乘法），FFN 是模型中主要的非线性来源

类比理解：如果注意力是"收集信息"，FFN 就是"消化信息"。注意力决定看哪里，FFN 决定怎么处理看到的东西。

关键要点：
  • FFN 参数量：2 × d_model × d_ff = 2 × 512 × 2048 ≈ 2M，是模型中参数量最大的组件
  • 所有位置共享同一组 W_1, W_2 权重（相当于 1D 卷积，kernel_size=1）
  • 输入输出形状不变：[batch, seq_len, d_model]

工作原理深度拆解

FFN 虽然只有一行代码，但包含三个关键操作：

  1. W_1 升维：self.w_1(x) 把 [B,L,512] 映射到 [B,L,2048]。这一步把每个 token 的特征向量扩展到一个更高维的空间，相当于给模型更多的“内部表达位”来组合特征。
  2. ReLU 非线性：F.relu(...) 把负值截断为 0。如果没有 ReLU，两层线性层叠加仍然只是一个线性变换，模型表达能力会大幅下降。ReLU 让模型可以学习“如果某个组合特征大于阈值就激活”的模式。
  3. W_2 降维：self.w_2(...) 把 [B,L,2048] 压缩回 [B,L,512]。这一步从 2048 维的高维表达里筛选出最有用的 512 维信息，同时保证残差连接时维度匹配。

为什么是 512→2048→512？

论文里 d_ff = 4 × d_model。升维 4 倍是一个经验折中：

  • 升得不够（如 512→1024→512）：内部表达空间不足，非线性变换能力弱
  • 升得太多（如 512→8192→512）：参数量和计算量暴增，容易过拟合
  • 4 倍在表达能力和效率之间取得了平衡

数值直觉

x = [0.5, -0.3, 1.2, -0.8]   # 4维
W_1 把 x 映射到 8 维: [0.2, 1.5, -0.4, 0.0, 0.9, -1.1, 0.3, 0.7]
ReLU: [0.2, 1.5, 0.0, 0.0, 0.9, 0.0, 0.3, 0.7]

Layer Normalization 层归一化

class LayerNorm(nn.Module):
    """层归一化：对每个样本的特征维度做归一化"""

    def __init__(self, d_model, eps=1e-6):
        super().__init__()
        # 可学习的缩放和平移参数
        self.gamma = nn.Parameter(torch.ones(d_model))  # 缩放
        self.beta = nn.Parameter(torch.zeros(d_model))   # 平移
        self.eps = eps  # 防止除零的小常数

    def forward(self, x):
        """
        x: [batch_size, seq_len, d_model]
        return: [batch_size, seq_len, d_model]

        对最后一个维度（d_model）做归一化
        """
        # 计算最后一个维度的均值和标准差
        mean = x.mean(-1, keepdim=True)     # [batch, seq_len, 1]
        std = x.std(-1, keepdim=True)       # [batch, seq_len, 1]

        # 归一化：(x - mean) / (std + eps)
        # 然后用 gamma 缩放、beta 平移
        normalized = (x - mean) / (std + self.eps)
        return self.gamma * normalized + self.beta

语义描述

LayerNorm 对每个 token 的特征维度做归一化，使每个位置的向量分布稳定（均值≈0，方差≈1），然后用 gamma 和 beta 恢复模型需要的分布。

为什么用 LayerNorm 而不是 BatchNorm？

  • 序列长度可变：BatchNorm 需要固定 batch 统计，不同序列长度会导致统计量不稳定
  • 推理与训练一致：BatchNorm 在推理时使用运行均值/方差，序列任务中可能不一致
  • 逐样本独立：LayerNorm 对每个样本独立计算，不受 batch 中其他样本影响

gamma 和 beta 是可学习参数，让模型自己决定归一化后的最佳分布（不一定是标准正态分布）。

工作原理深度拆解：
  • Step 1: 求均值：mean = x.mean(-1, keepdim=True)。对最后一个维度（特征维 d_model）求平均，每个 token 得到一个均值标量。
  • Step 2: 求标准差：std = x.std(-1, keepdim=True)。同样是每个 token 独立计算，标准差用于衡量该 token 各维度上的“分散程度”。
  • Step 3: 归一化：(x - mean) / (std + eps)。每个 token 被调整为均值 0、方差 1 附近。eps 防止除零。
  • Step 4: 缩放和平移：gamma * normalized + beta。gamma 和 beta 是可学习参数，让模型自己决定最终分布的均值和方差。

数值示例（d_model=3）

mean = 4.0, std = 1.633
normalized = ([2,4,6] - 4.0) / 1.633 = [-1.225, 0.0, 1.225]
gamma = [1.0, 1.0, 1.0], beta = [0.0, 0.0, 0.0]
output = [-1.225, 0.0, 1.225]

# output = [-1.45, 1.0, 3.45]

SublayerConnection 残差连接 + 层归一化

class SublayerConnection(nn.Module):
    """残差连接 + LayerNorm：Transformer 中每个子层的标准包装"""

    def __init__(self, d_model, dropout=0.1):
        super().__init__()
        self.norm = LayerNorm(d_model)
        self.dropout = nn.Dropout(dropout)

    def forward(self, x, sublayer):
        """
        x: [batch, seq_len, d_model]        子层输入
        sublayer: callable                  子层函数（如注意力或 FFN）

        return: [batch, seq_len, d_model]

        执行：LayerNorm(x + Dropout(sublayer(x)))
        """
        # 先对 x 做 LayerNorm，再传入子层，然后做残差连接
        return x + self.dropout(sublayer(self.norm(x)))

语义描述

这是 Transformer 中每个子层（注意力、FFN）的标准包装模式，实现了论文中的 "Add & Norm" 操作。它做两件事：

  • 残差连接（Add）：x + sublayer(x)。让梯度可以直接流过残差路径，缓解深层网络的梯度消失问题。即使子层学不到有用信息，原始信息也不会丢失
  • 层归一化（Norm）：对输入先做 LayerNorm 再传入子层（Pre-Norm 结构）。稳定每层的输入分布，加速训练收敛

这里采用 Pre-Norm（先 Norm 再 Sublayer）而非论文原始的 Post-Norm（先 Sublayer 再 Norm），因为 Pre-Norm 训练更稳定，在现代实现中被广泛采用。

Dropout 在子层输出上施加，防止过拟合。残差连接绕过 Dropout，保证原始信息完整传递。

关键要点：
  • 残差连接要求子层输入输出维度相同（都是 d_model）
  • SublayerConnection 是一个通用包装器，可以包装任何子层
  • Encoder 中使用 2 个（注意力 + FFN），Decoder 中使用 3 个（注意力 + 交叉注意力 + FFN）

工作原理深度拆解

return x + self.dropout(sublayer(self.norm(x))) 这一行是 Transformer 训练稳定性的关键，拆开看：

  1. self.norm(x)：先把输入 x 归一化，稳定分布。这是 Pre-Norm 结构（先 Norm 再子层）。
  2. sublayer(...)：子层（注意力或 FFN）处理归一化后的输入。因为输入分布稳定，梯度不会爆炸/消失。
  3. self.dropout(...)：对子层输出随机置零一部分维度，防止过拟合。
  4. x + ...：残差连接。即使 dropout 把某些维度置零，原始 x 仍然完整保留，信息可以无损传播。

Pre-Norm vs Post-Norm

  • Post-Norm（原始论文）：LayerNorm(x + sublayer(x))。残差路径上的梯度会经过 LayerNorm，深层时梯度仍然可能不稳定。
  • Pre-Norm（本实现）：x + sublayer(LayerNorm(x))。残差路径直接绕过 LayerNorm，梯度传播更稳定，现在几乎成为标准做法。

数值直觉

x = [1.0, 2.0, 3.0]
norm(x) = [-1.225, 0.0, 1.225]
sublayer(norm(x)) = [0.1, 0.2, -0.3]
dropout(...) = [0.1, 0.0, -0.3]  # 第二个维度被随机置零
output = x + dropout_out = [1.1, 2.0, 2.7]
# 即使 dropout 把某些信息扔了，x 的原始信息还在

Encoder Layer 编码器层 Encoder

class EncoderLayer(nn.Module):
    """编码器单层：自注意力 + 前馈网络"""

    def __init__(self, d_model, n_heads, d_ff, dropout=0.1):
        super().__init__()
        # 子层1：多头自注意力
        self.self_attn = MultiHeadAttention(d_model, n_heads, dropout)
        # 子层2：位置前馈网络
        self.feed_forward = PositionwiseFeedForward(d_model, d_ff, dropout)
        # 两个 SublayerConnection 包装器
        self.sublayer1 = SublayerConnection(d_model, dropout)
        self.sublayer2 = SublayerConnection(d_model, dropout)

    def forward(self, x, mask=None):
        """
        x: [batch, seq_len, d_model]  编码器输入
        mask: padding mask 或 None

        return: [batch, seq_len, d_model]  编码器输出
        """
        # 子层1：自注意力 —— 每个位置关注所有位置
        # Q=K=V=x，即 self-attention
        x = self.sublayer1(x, lambda x: self.self_attn(x, x, x, mask))

        # 子层2：前馈网络 —— 对每个位置做非线性变换
        x = self.sublayer2(x, self.feed_forward)

        return x

语义描述

EncoderLayer 是编码器的基本构建单元，包含两个子层：

  1. Multi-Head Self-Attention：Q=K=V=同一个输入，让序列中每个 token 与所有 token（包括自己）计算注意力。这一步建立了全局依赖关系，每个位置都能"看到"整个序列
  2. Feed-Forward Network：对注意力输出做逐位置的非线性变换，增加模型表达能力

每个子层都被 SublayerConnection 包装（残差 + LayerNorm），确保信息流畅和训练稳定。

mask 在这里通常用于屏蔽 padding 位置，防止模型关注到无意义的 padding token。

Decoder Layer 解码器层 Decoder

class DecoderLayer(nn.Module):
    """解码器单层：掩码自注意力 + 交叉注意力 + 前馈网络"""

    def __init__(self, d_model, n_heads, d_ff, dropout=0.1):
        super().__init__()
        # 子层1：掩码多头自注意力
        self.self_attn = MultiHeadAttention(d_model, n_heads, dropout)
        # 子层2：交叉注意力（Q来自Decoder，KV来自Encoder）
        self.cross_attn = MultiHeadAttention(d_model, n_heads, dropout)
        # 子层3：位置前馈网络
        self.feed_forward = PositionwiseFeedForward(d_model, d_ff, dropout)
        # 三个 SublayerConnection 包装器
        self.sublayer1 = SublayerConnection(d_model, dropout)
        self.sublayer2 = SublayerConnection(d_model, dropout)
        self.sublayer3 = SublayerConnection(d_model, dropout)

    def forward(self, x, enc_output, src_mask=None, tgt_mask=None):
        """
        x:          [batch, tgt_len, d_model]    解码器输入
        enc_output: [batch, src_len, d_model]     编码器输出
        src_mask:   padding mask for encoder output
        tgt_mask:   causal mask + padding mask for decoder input

        return: [batch, tgt_len, d_model]
        """
        # 子层1：掩码自注意力 —— 每个位置只能看到当前及之前的位置
        # tgt_mask 是因果掩码（下三角），防止"偷看"未来信息
        x = self.sublayer1(x, lambda x: self.self_attn(x, x, x, tgt_mask))

        # 子层2：交叉注意力 —— Q来自Decoder，K=V来自Encoder
        # 让解码器在生成每个token时，参考编码器的源序列信息
        x = self.sublayer2(x, lambda x: self.cross_attn(x, enc_output, enc_output, src_mask))

        # 子层3：前馈网络 —— 逐位置非线性变换
        x = self.sublayer3(x, self.feed_forward)

        return x

语义描述

DecoderLayer 比 EncoderLayer 多一个子层，共三个：

  1. Masked Self-Attention：Q=K=V=解码器输入，但加上因果掩码（causal mask）。位置 i 只能关注位置 0~i，不能关注未来位置 i+1, i+2...。这保证了自回归生成：预测第 i 个 token 时看不到第 i 个 token 的答案
  2. Cross-Attention：Q 来自解码器，K=V 来自编码器输出。这是 Encoder 和 Decoder 之间唯一的交互通道。解码器通过这一层"查询"编码器输出中最相关的信息，决定生成什么
  3. Feed-Forward Network：与前两个子层的注意力交互后，做非线性特征变换

三种 mask 的区分：

  • tgt_mask：用于子层1，是因果掩码 + padding 掩码的组合
  • src_mask：用于子层2，是编码器输出的 padding 掩码
关键要点：
  • Decoder 比 Encoder 多一个 Cross-Attention 子层
  • 因果掩码是上三角矩阵（上半部分为 0），使 softmax 后未来位置权重为 0
  • Cross-Attention 是 Encoder→Decoder 信息传递的唯一路径

Encoder 编码器 Encoder

class Encoder(nn.Module):
    """完整编码器：嵌入 + 位置编码 + N层EncoderLayer"""

    def __init__(self, vocab_size, d_model, n_heads, d_ff, n_layers, dropout=0.1):
        super().__init__()
        # 词嵌入：将 token ID 转为 d_model 维向量
        self.embedding = nn.Embedding(vocab_size, d_model)
        # 位置编码：注入位置信息
        self.pos_encoding = PositionalEncoding(d_model)
        # N 层 EncoderLayer 堆叠
        self.layers = nn.ModuleList([
            EncoderLayer(d_model, n_heads, d_ff, dropout)
            for _ in range(n_layers)
        ])
        # 最终的 LayerNorm（Pre-Norm 结构需要）
        self.norm = LayerNorm(d_model)
        # Dropout
        self.dropout = nn.Dropout(dropout)

    def forward(self, x, mask=None):
        """
        x:    [batch, src_len]         源序列 token IDs
        mask: [batch, 1, 1, src_len]   padding mask

        return: [batch, src_len, d_model]  编码器输出
        """
        # Step 1: 词嵌入 + 缩放
        # 乘以 sqrt(d_model) 是为了让位置编码的量级与嵌入相当
        x = self.embedding(x) * math.sqrt(self.embedding.embedding_dim)

        # Step 2: 加位置编码
        x = self.pos_encoding(x)

        # Step 3: Dropout
        x = self.dropout(x)

        # Step 4: 依次通过 N 层 EncoderLayer
        for layer in self.layers:
            x = layer(x, mask)

        # Step 5: 最终 LayerNorm
        x = self.norm(x)

        return x

语义描述

Encoder 是完整的编码器模块，将源序列 token IDs 转换为富含上下文信息的向量表示。处理流程：

  1. Embedding：将离散的 token ID 映射为连续的 d_model 维向量。乘以 sqrt(d_model) 是为了放大嵌入值，使其与位置编码的量级匹配
  2. Positional Encoding：加上位置编码，注入位置信息
  3. N 层 EncoderLayer：依次通过 N 个编码器层（论文中 N=6）。每层进一步提炼序列表示，低层捕捉局部/语法关系，高层捕捉语义/全局关系
  4. 最终 LayerNorm：Pre-Norm 结构需要在最后做一次额外的 LayerNorm

编码器的输出有两用途：传给解码器的 Cross-Attention 作为 K/V，也可直接用于分类等下游任务。

Decoder 解码器 Decoder

class Decoder(nn.Module):
    """完整解码器：嵌入 + 位置编码 + N层DecoderLayer"""

    def __init__(self, vocab_size, d_model, n_heads, d_ff, n_layers, dropout=0.1):
        super().__init__()
        # 词嵌入：将目标序列 token ID 转为向量
        self.embedding = nn.Embedding(vocab_size, d_model)
        # 位置编码
        self.pos_encoding = PositionalEncoding(d_model)
        # N 层 DecoderLayer 堆叠
        self.layers = nn.ModuleList([
            DecoderLayer(d_model, n_heads, d_ff, dropout)
            for _ in range(n_layers)
        ])
        # 最终 LayerNorm
        self.norm = LayerNorm(d_model)
        # Dropout
        self.dropout = nn.Dropout(dropout)

    def forward(self, x, enc_output, src_mask=None, tgt_mask=None):
        """
        x:          [batch, tgt_len]         目标序列 token IDs（右移一位）
        enc_output: [batch, src_len, d_model] 编码器输出
        src_mask:   [batch, 1, 1, src_len]   源序列 padding mask
        tgt_mask:   [batch, 1, tgt_len, tgt_len]  目标序列因果+padding mask

        return: [batch, tgt_len, d_model]  解码器输出
        """
        # Step 1: 词嵌入 + 缩放
        x = self.embedding(x) * math.sqrt(self.embedding.embedding_dim)

        # Step 2: 加位置编码
        x = self.pos_encoding(x)

        # Step 3: Dropout
        x = self.dropout(x)

        # Step 4: 依次通过 N 层 DecoderLayer
        # 每层都接收编码器输出用于 Cross-Attention
        for layer in self.layers:
            x = layer(x, enc_output, src_mask, tgt_mask)

        # Step 5: 最终 LayerNorm
        x = self.norm(x)

        return x

语义描述

Decoder 是完整的解码器模块，负责自回归地生成目标序列。处理流程与编码器类似，但有两个关键区别：

  1. 输入右移一位：训练时，Decoder 的输入是目标序列右移一位（在开头加上 <sos> token）。这样位置 i 的输入是目标序列的第 i-1 个 token，模型需要预测第 i 个 token。这保证了训练和推理的一致性
  2. 每层都接收编码器输出：Decoder 的每一层都通过 Cross-Attention 与编码器输出交互，而不仅仅是在最后使用一次

推理时的自回归生成流程：

  • Step 1: 输入 <sos>，模型预测第一个 token
  • Step 2: 将预测的 token 加入输入序列，预测第二个 token
  • Step 3: 重复直到生成 <eos> 或达到最大长度

Transformer 完整模型 Full Model

class Transformer(nn.Module):
    """完整的 Transformer 模型：Encoder + Decoder + Output Projection"""

    def __init__(self, src_vocab_size, tgt_vocab_size,
                 d_model=512, n_heads=8, d_ff=2048,
                 n_layers=6, dropout=0.1):
        super().__init__()
        # 编码器
        self.encoder = Encoder(
            src_vocab_size, d_model, n_heads, d_ff, n_layers, dropout
        )
        # 解码器
        self.decoder = Decoder(
            tgt_vocab_size, d_model, n_heads, d_ff, n_layers, dropout
        )
        # 输出投影层：将 d_model 维向量映射到词表大小
        self.output_proj = nn.Linear(d_model, tgt_vocab_size)

        # 权重初始化（Xavier 初始化）
        self._init_weights()

    def _init_weights(self):
        """Xavier 均匀初始化所有参数"""
        for p in self.parameters():
            if p.dim() > 1:
                nn.init.xavier_uniform_(p)

    def forward(self, src, tgt, src_mask=None, tgt_mask=None):
        """
        src: [batch, src_len]   源序列 token IDs
        tgt: [batch, tgt_len]   目标序列 token IDs（右移一位）
        src_mask: padding mask for source
        tgt_mask: causal + padding mask for target

        return: [batch, tgt_len, tgt_vocab_size]  log 概率
        """
        # Step 1: 编码器处理源序列
        enc_output = self.encoder(src, src_mask)
        # enc_output: [batch, src_len, d_model]

        # Step 2: 解码器处理目标序列 + 交叉注意力
        dec_output = self.decoder(tgt, enc_output, src_mask, tgt_mask)
        # dec_output: [batch, tgt_len, d_model]

        # Step 3: 线性投影到词表大小
        logits = self.output_proj(dec_output)
        # logits: [batch, tgt_len, tgt_vocab_size]

        # Step 4: log-softmax（配合 NLLLoss 使用）
        return F.log_softmax(logits, dim=-1)


# ==================== 辅助函数 ====================

def make_src_mask(src, pad_idx=0):
    """创建源序列 padding mask
    src: [batch, src_len]
    return: [batch, 1, 1, src_len]  pad 位置为 0，非 pad 位置为 1
    """
    return (src != pad_idx).unsqueeze(1).unsqueeze(2)

def make_tgt_mask(tgt, pad_idx=0):
    """创建目标序列 mask（因果掩码 + padding 掩码）
    tgt: [batch, tgt_len]
    return: [batch, 1, tgt_len, tgt_len]
    """
    tgt_len = tgt.size(1)
    # 因果掩码：下三角矩阵（位置 i 只能看到 0~i）
    causal_mask = torch.tril(torch.ones(tgt_len, tgt_len)).bool()
    # padding 掩码
    pad_mask = (tgt != pad_idx).unsqueeze(1).unsqueeze(2)  # [batch, 1, 1, tgt_len]
    # 合并：两个条件都满足才为 True
    tgt_mask = causal_mask.unsqueeze(0) & pad_mask
    return tgt_mask

语义描述

这是 Transformer 的完整模型，将 Encoder 和 Decoder 组合在一起，加上输出投影层。完整的前向传播流程：

  1. 编码阶段：源序列 → Encoder → 上下文向量（enc_output），编码了源序列的完整语义
  2. 解码阶段：目标序列（右移）→ Decoder（与 enc_output 交叉注意力）→ 解码向量，融合了源序列信息和已生成序列信息
  3. 输出投影：Linear 将 d_model 维映射到词表大小，得到每个位置的 logits
  4. Softmax：转为 log 概率，配合 NLLLoss 计算损失

Mask 生成函数的语义：

  • make_src_mask：屏蔽源序列中的 padding token，防止注意力关注无意义位置
  • make_tgt_mask：因果掩码（下三角）+ padding 掩码的组合。因果掩码确保位置 i 只能看到 0~i，padding 掩码确保不关注 padding

Xavier 初始化确保各层初始激活值的方差大致相同，有利于深层网络的训练稳定性。

默认参数（论文设置）：
  • d_model = 512, n_heads = 8, d_ff = 2048, n_layers = 6
  • 每头维度 d_k = 512/8 = 64
  • 总参数量 ≈ 40-65M（取决于词表大小）
  • 输出：[batch, tgt_len, tgt_vocab_size] 的 log 概率
Section 12

Mask 机制深度对比：Encoder vs Decoder

核心问题

Transformer 中有三处使用了 scaled_dot_product_attention，每处的 mask 配置完全不同。很多学习者在读到 Encoder 的 self-attention 时会产生疑问：Encoder 中也用了 attention 公式，那它的 mask 是什么？和 Decoder 的 mask 有什么区别？

答案是：Encoder 只用 padding mask，Decoder 的 masked self-attention 用 causal mask + padding mask，Decoder 的 cross-attention 只用 source padding mask。下面逐个拆解。

三种 Mask 全景对照

使用位置 Mask 类型 作用 形状
Encoder Self-Attention Padding Mask 屏蔽源序列中的 padding token [B, 1, 1, src_len]
Decoder Masked Self-Attention Causal Mask + Padding Mask 屏蔽未来位置 + padding token [B, 1, tgt_len, tgt_len]
Decoder Cross-Attention Source Padding Mask 屏蔽编码器输出中的 padding 位置 [B, 1, 1, src_len]

A. Encoder Self-Attention 的 Mask

语义描述

Encoder 是双向的——每个位置可以自由地关注序列中所有位置（前和后），不存在"未来"概念。因此 Encoder 不需要因果掩码。

它需要的唯一 mask 是 Padding Mask：在 batch 化处理时，不同长度的序列会被填充到同一长度，填充位置（pad_idx）是无意义的，不应该参与注意力计算。

核心逻辑：

  • pad 位置对应的 mask 值为 0（被屏蔽）
  • 真实 token 位置对应的 mask 值为 1（参与注意力）
  • mask 形状 [B, 1, 1, src_len]：第 1 维为 1 会广播到所有 head，第 2 维为 1 会广播到所有 query 位置
# ==================== Encoder 的 Mask ====================

def make_src_mask(src, pad_idx=0):
    """
    Encoder Self-Attention 使用的 mask：Padding Mask

    src: [batch_size, src_len]  源序列 token IDs
         例: [ [5, 12, 8, 0, 0],       # 长度3, pad 2个
               [3, 7, 9, 14, 0] ]      # 长度4, pad 1个

    return: [batch_size, 1, 1, src_len]
            pad 位置为 False, 真实 token 位置为 True
    """
    # src != pad_idx  →  [B, src_len]  布尔矩阵
    # True = 真实 token, False = padding
    mask = (src != pad_idx)                        # [B, src_len]

    # 增加维度以便在 attention 中广播
    # [B, src_len] → [B, 1, 1, src_len]
    # dim=1 (head 维) = 1 → 广播到所有头
    # dim=2 (query 维) = 1 → 广播到所有 query 位置
    mask = mask.unsqueeze(1).unsqueeze(2)          # [B, 1, 1, src_len]

    return mask

# ------------------- 示意图解 -------------------
# 假设 src = [ [5, 12, 8, 0, 0] ]  (1个样本, 长度5, 前3个是真实token, 后2个是pad)
#
# src != 0 的结果:
#   [True, True, True, False, False]
#
# unsqueeze 后的 mask [1, 1, 1, 5]:
#   [[[  [1, 1, 1, 0, 0]  ]]]
#
# 在 scaled_dot_product_attention 中:
#   scores 形状: [B, H, src_len, src_len] = [1, 8, 5, 5]
#   mask 广播:   [1, 1, 1, 5] → [1, 8, 5, 5]
#
#   scores 被 mask 后 (0 的位置填充 -1e9):
#
#          key →   0    1    2    3    4
#   query ↓     ┌────┬────┬────┬────┬────┐
#        0      │ s  │ s  │ s  │ -∞ │ -∞ │   ← 每个query都不关注pad位置
#        1      │ s  │ s  │ s  │ -∞ │ -∞ │
#        2      │ s  │ s  │ s  │ -∞ │ -∞ │
#        3      │ s  │ s  │ s  │ -∞ │ -∞ │   ← pad query行也有值,
#        4      │ s  │ s  │ s  │ -∞ │ -∞ │     但这些行后续不会使用
#                └────┴────┴────┴────┴────┘
#   (s = 原始 score 值; -∞ 表示被 mask 掉)
#
# 注意: Encoder 中 query 维不 mask, 所有位置都能被其他位置关注
#       只有 key 维被 mask (pad 位置不被关注)
关键要点：
  • Encoder mask 只屏蔽 Key 维度上的 padding 位置，不限制 Query 维度
  • Encoder 没有"未来"概念，所有位置双向可见
  • mask 形状 [B, 1, 1, src_len] 中两个 1 分别用于广播到 heads 和 query 位置

B. Decoder Masked Self-Attention 的 Mask

语义描述

Decoder 是自回归的——生成第 i 个 token 时，只能看到第 0 ~ i 个位置，不能"偷看"未来。因此 Decoder 的 masked self-attention 需要两种 mask 叠加：

  • Causal Mask（因果掩码）：下三角矩阵，位置 (i, j) 中 j > i 的位置被屏蔽。保证位置 i 只关注 0~i。
  • Padding Mask：与 Encoder 相同，屏蔽 padding token。

两者通过逻辑与（&）合并：只有"在因果范围内"且"不是 padding"的位置才允许参与注意力。

核心区别：这里 mask 形状是 [B, 1, tgt_len, tgt_len]——Query 维度不再是 1，因为不同 query 位置能看到的 key 范围不同（位置 0 只能看到 1 个，位置 4 能看到 5 个）。

# ==================== Decoder Masked Self-Attention 的 Mask ====================

def make_tgt_mask(tgt, pad_idx=0):
    """
    Decoder Masked Self-Attention 使用的 mask：Causal Mask + Padding Mask

    tgt: [batch_size, tgt_len]  目标序列 token IDs
         例: [ [2, 5, 12, 8, 0, 0] ]   # 长度4, pad 2个 (=2)

    return: [batch_size, 1, tgt_len, tgt_len]  布尔矩阵
    """
    tgt_len = tgt.size(1)

    # ---- Part 1: Causal Mask (因果掩码) ----
    # 下三角矩阵: 位置 (i, j) 中 j <= i 为 True, j > i 为 False
    #
    #   tgt_len = 6 时:
    #      j →  0    1    2    3    4    5
    #   i ↓     ┌────┬────┬────┬────┬────┬────┐
    #   0       │ 1  │ 0  │ 0  │ 0  │ 0  │ 0  │   ← 位置0只能看到0
    #   1       │ 1  │ 1  │ 0  │ 0  │ 0  │ 0  │   ← 位置1能看到0,1
    #   2       │ 1  │ 1  │ 1  │ 0  │ 0  │ 0  │
    #   3       │ 1  │ 1  │ 1  │ 1  │ 0  │ 0  │
    #   4       │ 1  │ 1  │ 1  │ 1  │ 1  │ 0  │
    #   5       │ 1  │ 1  │ 1  │ 1  │ 1  │ 1  │   ← 位置5能看到0~5
    #           └────┴────┴────┴────┴────┴────┘
    #
    causal_mask = torch.tril(
        torch.ones(tgt_len, tgt_len)
    ).bool()                                     # [tgt_len, tgt_len]

    # ---- Part 2: Padding Mask ----
    # 与 Encoder 相同: 真实 token 为 True, pad 为 False
    # [B, tgt_len] → [B, 1, 1, tgt_len]
    pad_mask = (tgt != pad_idx)                   # [B, tgt_len]
    pad_mask = pad_mask.unsqueeze(1).unsqueeze(2) # [B, 1, 1, tgt_len]

    # ---- Part 3: 合并两个 mask ----
    # causal_mask: [tgt_len, tgt_len] → [1, 1, tgt_len, tgt_len]
    # pad_mask:    [B, 1, 1, tgt_len] → 广播到 [B, 1, tgt_len, tgt_len]
    #
    # 合并规则: 逻辑与 (&)
    #   某位置 (i, j) 允许关注 ⟺ j <= i (因果) AND j 不是 pad (padding)
    #
    # tgt = [2, 5, 12, 8, 0, 0] 时的最终 mask [1, 1, 6, 6]:
    #
    #      key →  0    1    2    3    4    5
    #   query↓    ┌────┬────┬────┬────┬────┬────┐
    #   0         │ 1  │ 0  │ 0  │ 0  │ 0  │ 0  │   ← 只看到位置0
    #   1         │ 1  │ 1  │ 0  │ 0  │ 0  │ 0  │   ← 看到0,1
    #   2         │ 1  │ 1  │ 1  │ 0  │ 0  │ 0  │   ← 看到0,1,2
    #   3         │ 1  │ 1  │ 1  │ 1  │ 0  │ 0  │   ← 看到0,1,2,3
    #   4         │ 1  │ 1  │ 1  │ 1  │ 0  │ 0  │   ← pad位置4: 全部禁止(行清零)
    #   5         │ 1  │ 1  │ 1  │ 1  │ 0  │ 0  │   ← pad位置5: 全部禁止(行清零)
    #             └────┴────┴────┴────┴────┴────┘
    #   注意: 第4、5行虽然因果mask允许部分位置, 但因为query本身是pad,
    #         pad_mask的query广播会使整行变0 (这些行后续不使用)
    #
    tgt_mask = causal_mask.unsqueeze(0) & pad_mask  # [B, 1, tgt_len, tgt_len]

    return tgt_mask
关键要点：
  • Decoder mask 同时限制 Query 维度和 Key 维度：因果 mask 限制"能看多远"，padding mask 限制"不看 pad"
  • mask 形状 [B, 1, tgt_len, tgt_len] 中 query 维 = tgt_len（每个 query 的可见范围不同）
  • 因果掩码是下三角（tril），不是上三角——位置 i 能看到 0~i，不能看到 i+1~
  • 合并用逻辑与而非相加，因为两个条件必须同时满足

C. Decoder Cross-Attention 的 Mask

语义描述

Cross-Attention 中 Q 来自 Decoder，K/V 来自 Encoder 输出。mask 只需要屏蔽 Key 侧（即 Encoder 输出的 padding 位置），不需要因果掩码——因为 Encoder 输出已经是完整处理后的表示，Decoder 的每个 query 位置都可以自由地关注 Encoder 输出的所有有效位置。

因此 Cross-Attention 使用的 mask 与 Encoder 的 mask 完全相同：src_mask = make_src_mask(src)。

# ==================== Cross-Attention 的 Mask ====================

# Cross-Attention: Q来自Decoder, K/V来自Encoder
#   Q: [B, tgt_len, d_model]    → Decoder 当前状态
#   K: [B, src_len, d_model]    → Encoder 输出
#   V: [B, src_len, d_model]    → Encoder 输出
#
# scores 形状: [B, H, tgt_len, src_len]
#              query是目标序列, key是源序列
#
# 需要屏蔽的是 src 中的 padding 位置 → 用 src_mask
# src_mask 形状: [B, 1, 1, src_len]  (与 Encoder 完全相同)
#
# 为什么不需要因果掩码?
#   - Encoder 输出是完整编码后的序列, 不存在"未来"概念
#   - Decoder 的每个位置都可以自由查看源序列的所有有效位置
#   - 因果约束只适用于 Decoder 自身的序列生成过程

# 在 DecoderLayer 中的调用:
#   self.cross_attn(x, enc_output, enc_output, src_mask)
#                              ↑               ↑
#                          K=V=enc_output    mask=src_mask

# ------------------- 示意图解 -------------------
# src = [5, 12, 8, 0, 0]  (src_len=5, 前3个有效, 后2个pad)
# tgt = [2, 5, 12]         (tgt_len=3)
#
# Cross-Attention scores [B, H, 3, 5]:
#
#          src key →  0    1    2    3    4
#   tgt query ↓      ┌────┬────┬────┬────┬────┐
#   0 (sos)          │ s  │ s  │ s  │ -∞ │ -∞ │
#   1                │ s  │ s  │ s  │ -∞ │ -∞ │
#   2                │ s  │ s  │ s  │ -∞ │ -∞ │
#                    └────┴────┴────┴────┴────┘
#   每个query都能看到所有有效src位置, 只是屏蔽src的pad
#   没有因果约束!

D. 三种 Mask 的完整代码对比

# ==================== 完整对比: 三种 Mask 的生成与使用 ====================

import torch

def make_src_mask(src, pad_idx=0):
    """
    [Encoder Self-Attention] 和 [Decoder Cross-Attention] 共用此 mask

    作用: 屏蔽源序列的 padding 位置
    特点: 只有 Key 维度被 mask, Query 维度不受限 (所有query都能看所有有效key)

    src: [B, src_len]
    return: [B, 1, 1, src_len]
    """
    return (src != pad_idx).unsqueeze(1).unsqueeze(2)


def make_tgt_mask(tgt, pad_idx=0):
    """
    [Decoder Masked Self-Attention] 专用

    作用: 屏蔽未来位置(causal) + 屏蔽 padding
    特点: Query 和 Key 维度都受限 (不同query能看到不同范围的key)

    tgt: [B, tgt_len]
    return: [B, 1, tgt_len, tgt_len]
    """
    tgt_len = tgt.size(1)

    # 因果掩码: 下三角
    causal_mask = torch.tril(torch.ones(tgt_len, tgt_len)).bool()

    # Padding 掩码
    pad_mask = (tgt != pad_idx).unsqueeze(1).unsqueeze(2)

    # 合并: 两个条件同时满足
    return causal_mask.unsqueeze(0) & pad_mask


# ==================== 使用方式对比 ====================

# ----- Encoder 中 -----
# EncoderLayer.forward(x, mask=src_mask)
#   → self.self_attn(x, x, x, src_mask)
#   Q=K=V=x (源序列), mask=src_mask
#   只屏蔽 padding, 双向注意力

# ----- Decoder 子层1 -----
# DecoderLayer.forward(x, enc_output, src_mask, tgt_mask)
#   → self.self_attn(x, x, x, tgt_mask)
#   Q=K=V=x (目标序列), mask=tgt_mask
#   屏蔽未来 + padding, 单向(自回归)注意力

# ----- Decoder 子层2 -----
#   → self.cross_attn(x, enc_output, enc_output, src_mask)
#   Q=x (目标序列), K=V=enc_output (源序列), mask=src_mask
#   只屏蔽源序列 padding, 无因果约束

E. 核心区别总结

Encoder mask vs Decoder mask — 五大区别

对比维度 Encoder Self-Attention Decoder Masked Self-Attention Decoder Cross-Attention
Mask 类型 仅 Padding Mask Causal + Padding 仅 Source Padding Mask
注意力方向 双向（全可见） 单向（只看过去） 全可见（源序列）
mask 形状 [B, 1, 1, src_len] [B, 1, tgt_len, tgt_len] [B, 1, 1, src_len]
Query 维受限? 否（=1, 广播） 是（=tgt_len） 否（=1, 广播）
需要因果掩码? 否 是 否

为什么 Encoder 不需要因果掩码？

Encoder 的任务是理解完整的源序列，不存在"预测下一个 token"的需求。每个位置都应该能看到整个序列以获得最丰富的上下文表示。例如在机器翻译中，翻译"I love you"时，编码"love"需要同时看到"I"和"you"才能正确理解语义。

为什么 Decoder 需要因果掩码？

Decoder 的任务是自回归地逐 token 生成。训练时虽然所有位置并行计算（teacher forcing），但因果掩码确保位置 i 的注意力只涉及 0~i，模拟推理时"已经生成的前 i 个 token"这一条件。如果没有因果掩码，训练时模型会"偷看"答案，导致推理时性能崩溃。

为什么 Cross-Attention 不需要因果掩码？

Cross-Attention 的 Key/Value 来自 Encoder 的完整输出，这是一个已经编码好的静态表示，不存在"未来"概念。Decoder 的每个位置都应该能自由查询源序列的所有有效位置。因果约束只适用于 Decoder 自身序列内部的生成顺序。

mask 在 attention 公式中的作用机制

三种 mask 最终都走同一条路径：scores.masked_fill(mask == 0, -1e9)。被 mask 的位置在 softmax 后权重趋近于 0，从而不参与对 V 的加权求和。区别只在于哪些位置被设为 0：

  • Encoder: 只有 (任意query, pad_key) 为 0
  • Decoder self-attn: (future_key, ...) 和 (..., pad_key) 和 (pad_query, ...) 都为 0
  • Cross-attn: 只有 (任意query, src_pad_key) 为 0
一句话记忆：

Encoder mask = "别看 pad"；Decoder self-attn mask = "别看 pad + 别偷看未来"；Cross-attn mask = "别看 Encoder 的 pad"。三者的底层逻辑完全相同（都是 masked_fill → -1e9 → softmax → 0），区别仅在于哪些位置被屏蔽。

三、核心设计思想总结

1. 注意力机制取代循环结构

RNN 通过时间步顺序处理序列，无法并行且长距离依赖建模弱。Transformer 用注意力机制让任意两个位置直接交互，距离为 O(1)，且整个序列可以并行计算。

2. 多头注意力 = 多视角理解

单头注意力只能学一种关注模式。多头将向量拆分到多个子空间，每个头独立学习不同的关注模式（如语法依赖、语义关系、位置模式等），最后拼接融合，显著增强模型的表达能力。

3. 缩放点积解决维度灾难

当 d_k 较大时，QK^T 的点积值会很大，使 softmax 进入饱和区（梯度趋近于 0）。除以 sqrt(d_k) 将点积方差稳定在 1 附近，保证梯度健康传播。

4. 残差连接 + LayerNorm 稳定深层训练

6 层堆叠（实际可达数十层）容易梯度消失/爆炸。残差连接提供梯度的直接通路，LayerNorm 稳定每层输入分布。两者结合使深层 Transformer 可稳定训练。

5. 位置编码弥补无序性

注意力机制本身是排列不变的（Permutation Invariant），无法感知顺序。位置编码通过 sin/cos 函数注入位置信息，使模型能理解序列的先后关系。不同频率的正弦波使模型能捕捉不同尺度的位置关系。

6. Mask 实现自回归生成

Decoder 通过因果掩码确保位置 i 只能看到 0~i 的信息，实现自回归生成。训练时所有位置并行计算（teacher forcing），推理时逐 token 生成。这种设计使训练高效而推理正确。

7. Cross-Attention 连接编码器和解码器

Cross-Attention 是 Encoder→Decoder 信息传递的唯一通道。Decoder 用自己的状态作为 Q，查询 Encoder 输出的 K/V，动态决定"生成当前 token 时应该关注源序列的哪些部分"。这种机制天然支持对齐（alignment），在翻译任务中表现为注意力权重矩阵可视化为源-目标对齐图。

四、参数与计算量分析

组件 参数量 占比 说明
Embedding ~2 × vocab × D 取决于词表 源 + 目标词表
Multi-Head Attention ~4D² per layer ~30% 每层 4 个线性层

五、一句话总结

Transformer = 位置编码（注入顺序）+ 多头注意力（全局交互）+ 前馈网络（非线性变换）+ 残差归一化（稳定训练），通过 Encoder-Decoder 架构和 Cross-Attention 实现序列到序列的建模，核心创新是用注意力机制取代循环结构，实现并行计算和长距离依赖建模。
