第0章 Scale-Up 网络概述与协议对比

0.1 什么是 Scale-Up 网络

Scale-Up 网络是 AI 大规模训练/推理中，将同一 Pod（计算域）内的 GPU/NPU 通过专用高速互联协议紧耦合连接的技术。 与 Scale-Out 网络（跨节点、基于以太网/InfiniBand）不同，Scale-Up 追求的是 内存语义、 纳秒级延迟、TB/s 级带宽，使得多颗 GPU 像一颗"大 GPU"一样工作。

Scale-Up vs Scale-Out 核心区别：
Scale-Up：GPU-GPU 间直接内存访问（Load/Store），延迟 < 1μs，带宽 TB/s 级，支持统一编址
Scale-Out：节点间网络通信（RDMA/Send-Recv），延迟 ~2-5μs，带宽 100s Gbps 级，需网络协议栈

NVIDIA NVLink 第1章 NVLink 协议

状态： 专有协议   当前版本： NVLink 5.0 (Blackwell)   首次发布： 2014年 (NVLink 1.0, P100)

NVLink 是 NVIDIA 开发的高速 GPU 互联技术，从第一代 160 GB/s 发展到第五代 1800 GB/s 双向带宽， 配合 NVSwitch 实现 GPU 全互联拓扑。NVLink 采用三层协议栈：事务层 (TL)、 数据链路层 (DL) 和 物理层 (PHY)，使用 P2P 架构和串行传输实现 GPU-GPU 通信。

  • Framing：将数据流组织为物理帧
  • Scrambling/Descrambling：数据扰码/解扰，降低 EMI

1.3 事务层 (TL)

1.3.1 Flit 结构

NVLink 采用 Flit（Flow Control Digit）模式组织数据，每个 Flit 为 128 bit（16 Byte）。 每个 NVLink 数据包包含 1~18 个 Flit，支持 0~16 个数据 Flit，最多传输 256B 数据。

总结

Scale-Up 网络协议正处于百花齐放、加速收敛的关键阶段。 NVLink 凭借垂直整合和 CUDA 生态仍是性能标杆； UB 以六层完整协议栈和万卡扩展能力引领国产方案； UALink 作为开放联盟标准正在汇聚行业合力； SUE 借助以太网生态试图统一 Scale-Up/Out； OLink 的网络总线化路线展现了独特的演进能力； OISA 的智能感知和在网计算开创了新方向； Alink 和 GLink 的芯片中立平台为多品牌混插提供了灵活选择； MTLink 在国产 GPU 互联领域持续迭代。

所有协议的共同追求是：更轻的协议头、更强的内存语义、 更可靠的链路层、更大的 Scale-Up 域。 未来 2-3 年，随着 UALink 2.0（缓存一致性）、ESUN/SUE-T 标准化、 以及国产协议生态成熟，Scale-Up 网络格局将从"一极主导"走向"多极共荣"。
