### 1. 如何删除 GitHub 中已有的项目目录？如何增加新项目目录？

- **分类**：Computer
- **问题描述**：用户需要了解如何在 GitHub 中删除已有仓库、创建新仓库，以及如何在仓库内管理文件夹。

**回答要点**：

- **删除仓库**：进入仓库 Settings → 滚动到底部 Danger Zone → Delete this repository → 输入 `用户名/仓库名` 确认
- **创建新仓库**：GitHub 页面点击 `+` → New repository，或使用 `gh repo create` 命令
- **本地创建并推送**：`git init` → `git add .` → `git commit` → `git remote add origin <url>` → `git push -u origin main`
- **仓库内删除文件夹**：`git rm -r <文件夹路径>` → commit → push
- **仓库内新增文件夹**：创建文件即可，空目录需用 `.gitkeep` 占位

**关键结论**：

- 删除 GitHub 仓库是不可逆操作，需谨慎
- Git 不跟踪空目录，新增空目录需放置 `.gitkeep` 占位文件
- 推送代码需要配置认证（Personal Access Token 或 SSH key）

**信息来源**：

- GitHub 官方文档：https://docs.github.com/repositories
